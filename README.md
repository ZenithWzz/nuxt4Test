# nuxt4Test

This repository contains a Nuxt 4 starter project configured with [Nuxt UI](https://ui.nuxt.com).

## Getting started

1. Install dependencies (Nuxt 4 RC and Nuxt UI):
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Generate a static site:
   ```bash
   npm run generate
   ```

The default page showcases Nuxt UI components to verify the installation.
